# Sekai Portal — Дорожная карта и Дневник разработки 🚀

Привет! В этом файле мы будем фиксировать весь наш прогресс, принятые архитектурные решения и текущие задачи. Это поможет нам всегда держать фокус и видеть, сколько крутых фич мы уже сделали!

---

## 🛠 Технологический стек проекта

- **Backend:** Laravel 11 (PHP 8.3)
- **Docker-окружение:** Laravel Sail (Nginx, MySQL 8.0, Redis, Mailpit)
- **Frontend:** Laravel Livewire 3 + Alpine.js (реактивный UI без лишнего JS-кода)
- **Стилизация:** Tailwind CSS v4 (ультрабыстрый современный CSS-движок)
- **Админ-панель:** Filament PHP v3 (лучший инструмент для быстрой разработки админок)
- **Локализация:** Мультиязычность (Русский / Английский) контента и интерфейса
- **Оплата:** Начнем с симуляции (для тестов), затем интегрируем Stripe API
